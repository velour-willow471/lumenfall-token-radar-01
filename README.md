Lumenfall Token Radar ranks 200 pre-token protocols from a sealed DefiLlama snapshot (as of 2026-11-14) by the implied value of a token they have not issued yet — TVL × a category multiple × 7-day growth × maturity × chain reach — and gives every protocol a concrete six-step farm plan with costs and times, on a static dashboard with a board, a detail view and a filter.

## Run it
```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
